# nextjs_typescript_materialui_usm_boilerplate

A Next.js + TypeScript starter with Material-UI and usm-redux state — the same shape as my Overmind boilerplate, with usm-redux swapped in.

## What's included

- **Next.js** with TypeScript and a `type-check` script
- **Material-UI** components
- **usm-redux** state on top of `react-redux` — classes and decorators instead of reducer boilerplate
- **SSR-safe `_document`** that injects MUI's server-side styles

## Project layout

```
pages/_app.tsx        redux provider + MUI theme
pages/_document.tsx   MUI server-side style injection
pages/index.tsx       your first page
```

## Getting started

```bash
git clone https://github.com/p32929/nextjs_typescript_materialui_usm_boilerplate.git
cd nextjs_typescript_materialui_usm_boilerplate
npm install
npm run dev        # http://localhost:3000

npm run build
npm run type-check
```
